# 验证记录

日期：2026-09-20。插件版本：0.1.0。

## 环境

- macOS arm64，Node.js 25.5.0。
- 从 npm 单独安装的官方 `@deepseek-ai/dsh@0.1.5-rc.1`，未修改其 UI bundle。
- 独立 `DSH_HOME`、独立 web profile，不使用个人设置或 API Key。
- Chromium 自动化验收，1280 × 900 桌面视口。
- 临时测试插件仅通过宿主 `workspaceRegistry.create` 创建演示工作区，
  不改变客户端插槽、设置服务或本插件行为。

## 已通过

- 构建和 9 项加载/模型单元测试。
- 原版宿主显示输入框星标，没有历史消息扩展也能加载。
- 在真实页面新增名称与正文并保存。
- 修改已有正文，刷新页面后仍能读取。
- 点击条目追加到已有草稿，原文保留、不自动发送。
- 取消删除保留条目；确认删除后刷新仍不再出现。
- 核对隔离宿主的设置文件，验证新增、修改和删除落盘。
- 390 × 844 视口中，插件列表弹层保持在水平边界内。
- 上述操作中未出现浏览器 `pageerror`。
- 用 README 的 `github:konglong87/dsh-input-list` 安装命令，从公开仓库安装到
  另一个独立 `DSH_HOME`，再次通过上述完整页面流程（不使用源码目录链接）。
- 未登录的 HTTP 请求读取公开 README 返回 200。

## 边界

- 这不是全部 dsh 版本、操作系统和浏览器的兼容认证。
- 窄屏检查只覆盖插件列表边界，不代表 dsh 整体移动布局完善。
- 未验证网络断开、多用户同时写入及设置服务故障的全部场景。
- 未验证实验历史消息插槽；正式核心功能不依赖它。
- 没有配置真实模型凭据，也没有发送模型请求。
